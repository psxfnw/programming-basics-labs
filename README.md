# Основи програмування: лабораторні 1.1–1.8

Кузьменко Віталій Юрійович, група Бд-F2-26-3-ПІ. Варіант 4.

Окремі папки містять вихідні файли кожної лабораторної. Файли з власним `main` збираються окремо.
Для `.c` використовується C17/GCC, для `.cpp` — C++17/G++.
C++ погоджено для 1.1, 1.4, 1.7 через посилання, оператор `::` та `new/delete` у методичці.

```sh
gcc -std=c17 -Wall -Wextra -Wpedantic lab-1.8/part2_bit_model.c -o bit-model
g++ -std=c++17 -O0 -g3 -Wall -Wextra -Wpedantic lab-1.7/memory.cpp -o memory
```

Короткі PDF у 1.1 та 1.7 містять фактичні результати GDB і пояснення відлагодження; титульних сторінок немає.
У 1.2–1.6 та 1.8 результати й потрібні пояснення відтворюються програмами та їхніми коментарями.
ЛР 1.6 виконує контрольоване дослідження байтового подання: небезпечне читання `double*` з int і порушення aliasing пояснені, але не виконуються.
У ЛР 1.7 режим `--leak-demo` навмисно демонструє витоки в окремому процесі; типовий режим звільняє пам’ять.

Перевірено на Windows x64, GCC/G++ 16.2.0 та GDB 18.1: 14 програм зібрано й запущено;
бітова модель пройшла 1251706 перевірок і перевірку захисту від NULL.
Графічний IDE/Watch не перевірено; відлагодження виконано в GDB.
